H&M Website Clone-
A front-end clone of the H&M homepage.

Live Demo: https://tushtigupta26.github.io/ 
Repository: https://github.com/TushtiGupta26/TushtiGupta26.github.io

Website Chosen-
H&M (https://www2.hm.com/)

Tech Stack-
HTML5,
CSS3

Features Implemented-
1. Header with H&M logo, navigation menu (Women, Male, Child, Home), and Sign Up / Log In links
2. Top banner for ongoing sale promotion
3. Hero section with sale banner
4. Category cards (Topwear, Bottoms, Accessories, Dresses) with discount tags and "Add to Cart" buttons
5. "New In" product grid with "Quick View" buttons
6. Promotional banners (New Arrivals, Festive 2026, H&M Beauty Essentials)
7. Footer with Shop, Corporate Info, and Help link columns, region selector, and membership sign-up prompt
8. Separate Sign Up and Log In pages with basic form validation
9. Fully responsive layout for desktop and mobile

Known Limitations-
1. Frontend only, no backend, so "Add to Cart," "Quick View," and navigation links are non-functional placeholders
2. Sign Up / Log In pages validate form input but do not connect to a real authentication system
3. Product images are static assets, not pulled from a live catalog
